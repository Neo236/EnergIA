# 🐍 Documentación de Data Science & Machine Learning

## 📌 Resumen
Documentación del proceso de exploración de datos (EDA), desarrollo, entrenamiento y evaluación del modelo predictivo para la clasificación de perfiles energéticos.

---

## 🔬 Metodología & Ciencia de Datos

1. **Exploración de Datos (EDA):** Limpieza, imputación y análisis de distribuciones.
2. **Feature Engineering:** Transformación de variables cuantitativas y cualitativas.
3. **Modelos Evaluados:**
   - Regresión Logística
   - Random Forest Classifier
   - Decision Trees
4. **Serialización del Modelo:** Exportado en formato `.pkl` o `.onnx`.
